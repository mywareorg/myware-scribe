** Make pipeline 

1. Diarization (force N speakers)
2. Clean turns (merge same-speaker, drop short)
3. Transcribe each turn independently
4. Write .txt + .json
*  Notes 
- No gpu acceleration
* Diarizen
- needs separate embedding model (wespeaker-voxceleb)
- repo bundles a fork of pyannotate.audio
- single venv (Python 3.11); see scripts/bootstrap.py
- VBxClustering ignores min/max speakers -> use AgglomerativeClustering
- transcribe per speaker turn so whisper timing never sets the speaker
* Components
- registry in scripts/components.py (--list to print)
- presets: speed / balanced / accuracy (default speed)
- speed: pyannote-seg3 + wespeaker-resnet34 + whisper-base.en (gated seg3)
- balanced: pyannote-seg3 + wespeaker-resnet34 + whisper-turbo (gated seg3)
- accuracy: diarizen-large + wespeaker-resnet34 + whisper-turbo (no token)
- override slots: --diarizer / --embedding / --transcriber
- preset shortcuts: --speed / --balanced / --accuracy (or --preset NAME)
- raw path overrides: --whisper-model / --diarizen-hub / --diarizen-embedding
* GPU
- bootstrap --vendor auto|cpu|cuda|rocm|mps (or TORCH_INDEX) picks torch wheels
- torch (diarization/embedding) runs on cuda/rocm/mps; --device auto
- CTranslate2 (whisper) is NVIDIA CUDA only -> CPU elsewhere
- threading: OMP/MKL set to physical cores; parallel whisper workers
